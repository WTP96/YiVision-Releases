# YiVision Releases

Official release assets and update manifests for YiVision.

This repository contains **release files only**. The YiVision application source code is maintained in the private repository:

- Source repository: https://github.com/WTP96/YiVision

## Downloads

Published stable releases will appear on the [Releases page](https://github.com/WTP96/YiVision-Releases/releases).

## Automatic updates

The application checks the stable update manifest at:

`https://github.com/WTP96/YiVision-Releases/releases/latest/download/latest.json`

Only signed Windows NSIS update artifacts are intended to be published here.

Do not upload source code, secrets, signing private keys, or user data to this repository.
